Try changing the chunking strategy, the embedding type, or editing the knowledge base, then run it again — the retrieved chunks and score will change.

Similarity here is computed with simplified vector representations (term-frequency vectors for "sparse", a fixed-size hashed vector for "dense"/"multimodal") so the math can run entirely in your browser — real RAG systems use dense neural embedding models. The LLM and Output stages show a templated response built from the retrieved text, not a real model call.
